Does not support DLsite Nest. Uses the same options as [DLsiteMetadata](https://github.com/Mysterken/DLsiteMetadata) except the search ones.

Individual files from the submodule are referenced instead of the whole project for compatibility.

### Game Installation

Clicking the install button will download and extract the archive. If it's a split archive, you will have to manually run the exe to extract it. Automatic uninstallation is unsupported.
